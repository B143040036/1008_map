GitHub Pages 部署教學指南

💡 什麼是 GitHub Pages？

GitHub Pages 是一項免費的靜態網頁寄存服務。本網頁採用「單一 HTML 檔案（Single-File Architecture）」設計，您可以直接將此檔案上傳至 GitHub 並一鍵發布上線！

1 建立 GitHub 專案（Repository）

登入您的 GitHub 帳號，點擊右上角 + 選擇 New repository。將專案命名（例如 kaohsiung-card-shops），設定為 Pública（公開），並點擊 Create repository。

2 上傳或新增 index.html 檔案

將本程式碼儲存並命名為 index.html。透過網頁上傳按鈕（upload an existing file）上傳至該專案根目錄，並點擊 Commit changes。

3 啟用 GitHub Pages 服務

進入專案的 Settings（設定）頁面，點擊左側選單的 Pages。在 Build and deployment 區塊中，將 Branch 設定為 main（或 master）與 / (root)，點擊 Save。

4 完成上線！

等待約 1 分鐘後重新整理頁面，上方就會出現您的專案上線網址（例如 https://yourusername.github.io/kaohsiung-card-shops/），點擊即可隨時隨地開啟您的高雄卡牌店地圖指南！
