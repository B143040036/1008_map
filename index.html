GitHub Pages 部署教學指南

💡 什麼是 GitHub Pages？

GitHub Pages 是一項免費的靜態網頁寄存服務。本網頁採用標準的單一 HTML 檔案架構結合 Leaflet.js 與 OpenStreetMap 圖磚，您可以直接將此檔案上傳至 GitHub 並一鍵發布上線！

  1. 登入您的 GitHub 帳號，點擊右上角 + 選擇 New repository。
  2. 將專案命名（例如 kaohsiung-card-shops），設定為公開，點擊 Create repository。
  3. 將本程式碼儲存並命名為 index.html 上傳至專案根目錄。
  4. 進入專案的 Settings ➔ Pages，將 Build and deployment 設定為 main 與 / (root) 並儲存。
  5. 等待約 1 分鐘後重新整理頁面，即可透過專案線上網址隨時隨地開啟地圖！
